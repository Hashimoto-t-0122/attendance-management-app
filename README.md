# 勤怠管理アプリ

## シンプルな操作で出勤・退勤を記録できる勤怠管理Webアプリ

社員番号とパスワードでログインし、出勤・退勤の登録や過去の勤怠履歴の確認ができるWebアプリケーションです。

## アプリケーション概要

社員の勤怠情報を簡単に登録・確認できる勤怠管理アプリです。
ログイン後の画面から出勤・退勤を登録でき、登録した勤怠情報を履歴一覧で確認できます。

### 主な機能

-ログイン
-出勤時刻の登録
-退勤時刻の登録
-勤怠履歴の一覧表示
-ログアウト
-勤怠データの保存

## 開発した背景

前職では日々の勤怠を紙に直接記入するというアナログ方法で記録していました。記録が正確なものである保証がない点、用紙の保管に手間がかかる点に特に不便さを感じており、業務システムの利便性が日々の業務効率に大きく影響することを実感しました。その経験から1クリックで勤怠情報を登録し、過去の記録を簡単に確認できるものがあれば便利だと感じ、今回のアプリ開発に取り組みました。

本アプリでは、社員がログインし、出勤・退勤を登録して、その履歴を確認するという勤怠管理の基本的な流れを実装しています。

## 🖥️ 画面・機能の説明

### 1. ログイン機能

社員番号とパスワードを入力してログインします。
登録されている社員情報と入力内容が一致した場合、勤怠管理画面へ移動します。
入力内容が正しくない場合は、エラーメッセージを表示します。

### 2. 出勤機能

「出勤」ボタンを押すことで、ログインしている社員の勤務日と出勤時刻を登録します。
同じ日にすでに出勤登録されている場合は、二重に登録されないようエラーメッセージを表示します。

### 3. 退勤機能

「退勤」ボタンを押すことで、当日の勤怠データに退勤時刻を登録します。
出勤記録が存在しない場合や、すでに退勤済みの場合はエラーメッセージを表示します。

### 4. 勤怠履歴表示機能

ログインしている社員の勤怠履歴を一覧で表示します。
以下の情報を確認できます。

-勤務日
-出勤時刻
-退勤時刻

### 5. ログアウト機能

「ログアウト」ボタンを押すことでログイン状態を解除し、ログイン画面へ戻ります。
